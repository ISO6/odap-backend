## odap-backend

### **项目概述**
ODAP Backend 是 Optical Data Analysis Platform（光通信数据分析平台）的核心后端服务，负责生产测试数据的采集、清洗、统计分析及业务处理，并向 Web、Power BI 及其他企业系统提供统一的数据接口服务。

项目基于 FastAPI 构建，遵循领域驱动设计（DDD）和模块化开发思想，支持生产数据分析、报表服务、MES/TAS 系统集成、设备测试数据追溯、良率分析及制造过程管控等业务场景。通过统一的日志追踪、异常处理、缓存机制和数据库连接池管理，确保系统具备良好的性能、稳定性和可维护性。

项目当前作为 ODAP 平台第二代技术架构（ODAP 2.0）的核心组成部分，逐步替代传统数据分析工具和脚本系统，为制造、质量、工程及管理团队提供标准化的数据服务能力。
